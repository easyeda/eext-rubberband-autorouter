# 调试方法说明

## 问题：eda is not defined

这是因为调试脚本需要在 EDA 扩展的上下文中运行。

## 正确的调试方法

### 方法 1: 查看扩展日志（推荐）

1. **打开布线配置面板**
   - 菜单栏 → 橡皮筋自动布线 → 关于 v2.7.3

2. **点击"开始布线"**

3. **查看配置面板中的日志**
   - 运行日志区域会显示详细的绕行日志
   - 特别是 `[Bypass]` 开头的日志

4. **截图发给我**
   - 配置面板的日志截图
   - 布线后的 PCB 截图

### 方法 2: 使用浏览器 Console

1. **打开布线配置面板**

2. **按 F12** 打开开发者工具

3. **切换到 Console 标签**

4. **应该能看到 `[Bypass]` 日志**
   - 这些日志是扩展代码输出的
   - 不需要运行额外脚本

### 方法 3: 在扩展环境中运行脚本

如果你确实需要运行调试脚本，请使用以下方法：

1. **打开布线配置面板**

2. **按 F12** 打开开发者工具

3. **在 Console 中输入**:
```javascript
window.parent.eda
```

4. **如果返回 eda 对象**，则可以运行调试脚本
5. **如果返回 undefined**，说明无法访问，请使用方法 1
