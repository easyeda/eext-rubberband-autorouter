# 调试指南 - v2.7.3

## 问题现状

布线后仍有导线交叉，需要获取详细的调试日志来分析问题。

## 调试步骤

### 方法 1: 使用调试脚本（推荐）

1. **打开 PCB 文档**

2. **运行自动布线**
   - 菜单栏 → 橡皮筋自动布线 → 开始自动布线

3. **打开浏览器开发者工具**
   - 按 `F12` 或 `Ctrl+Shift+I`
   - 切换到 **Console** 标签

4. **运行调试脚本**
   - 在 Console 中粘贴 `debug/drc-debug-script.ts` 的内容
   - 按 `Enter` 运行

5. **查看输出**
   - 记录 DRC 检查结果
   - 记录交叉数量
   - 记录间距违规数量

6. **提供以下信息**：
   - Console 中的 `[Bypass]` 日志
   - 调试脚本的输出
   - 布线后的截图
   - DRC 检查结果

### 方法 2: 查看扩展日志

1. **运行自动布线**

2. **观察配置面板日志**
   - 打开布线配置面板
   - 查看运行日志

3. **记录关键日志**：
   ```
   [Bypass] 开始生成绕行路径：(x, y) -> (x, y)
   [Bypass] 找到 X 个阻挡障碍物
     障碍物 1: 线段 (x1,y1) -> (x2,y2)
     障碍物 2: ...
   [Bypass] 尝试左侧绕行...
   [Bypass] 左侧绕行成功/失败
   [Bypass] 尝试右侧绕行...
   [Bypass] 右侧绕行成功/失败
   [Bypass] 尝试多点绕行...
   ```

## 需要收集的信息

请提供以下信息以便进一步分析：

1. **Console 日志**
   - 所有 `[Bypass]` 开头的日志
   - 网络布线日志

2. **调试脚本输出**
   - DRC 检查结果
   - 交叉数量
   - 间距违规数量

3. **截图**
   - 布线后的 PCB 截图
   - 显示交叉位置的放大图
   - Console 日志截图

4. **PCB 信息**
   - 网络数量
   - 大致尺寸（mm 或 mil）
   - 元件密度（稀疏/中等/密集）
